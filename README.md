# Harish K — Portfolio

AI & Full Stack Developer portfolio site.

## Deploy to Vercel

### Option 1 — Vercel CLI (fastest)
```bash
npm i -g vercel
vercel
```
Follow the prompts. The site will be live in ~30 seconds.

### Option 2 — Vercel Dashboard (no CLI)
1. Go to [vercel.com](https://vercel.com) and sign in
2. Click **Add New → Project**
3. Drag-and-drop this folder, or push it to GitHub first and import the repo
4. Click **Deploy** — no build settings needed (it's a static site)

## Project structure
```
harish-portfolio/
├── index.html      ← the entire site (HTML + CSS + JS)
├── vercel.json     ← Vercel routing config
└── README.md
```

## Local preview
Just open `index.html` in your browser — no build step required.
